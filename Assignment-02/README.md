# Assignment 02 - HTML5 Job Application Form
Built by **Shivam Raj** (B.Tech CSE, Invertis University).

## Implemented Features
- **Text Inputs:** `text`, `email`, `password`, `tel`, `url`, `number`
- **Choice Inputs:** `radio`, `checkbox`, `select` (`option`), `datalist`
- **Other Inputs:** `date`, `time`, `file`, `range`, `color`, `textarea`
- **Accessibility & Structure:** Explicit `<label for="...">` linked to every `id`, grouped using `<fieldset>` and `<legend>`
- **HTML5 Validation:** `required`, `placeholder`, `min`, `max`, `minlength`, `pattern`
- **Form Controls:** Submit (`type="submit"`) and Reset (`type="reset"`) buttons
