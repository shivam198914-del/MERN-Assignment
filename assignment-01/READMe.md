# Personal Portfolio Webpage - Shivam Raj

A multi-stage semantic HTML5 portfolio and resume webpage built to showcase my academic background, technical skills, and web development projects.

## Features Built
- **Semantic Structure:** Organized using HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`) for clean accessibility and SEO.
- **Internal Navigation:** Smooth section-jumping navigation bar using anchor links (`#about`, `#college`, `#skills`, `#education`, `#projects`, `#contact`) and a "Back to Top" link.
- **Structured Lists:** Includes unordered (`<ul>`), ordered (`<ol>`), and description (`<dl>`) lists to detail my course overview, core subjects, and learning roadmap at Invertis University.
- **Accessible Media:** Integrated personal portrait, campus photo, and project screenshots with descriptive `alt` attributes and `<figure>` captions.
- **SEO & Meta Tags:** Configured essential metadata including `charset`, `viewport`, `description`, and `author`.

## Project Structure
- `index.html` — Main portfolio webpage containing all seven development stages.
- `images/` — Folder containing `Portfolio-Potrait.jpeg`, `Invertis-Campus.png`, and `ScreenShot.png`.
